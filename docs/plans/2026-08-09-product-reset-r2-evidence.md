# R2 信息架构候选验收记录

## 已实现范围

- 起始区以继续最近项目、打开项目和无需 API Key 的示例为主；打开单文件及兼容设置保留在“更多”菜单。
- 窄窗口通过保持挂载的“下一步 / 真实代码 / 为什么重要”三面板切换保留阅读上下文。
- 路径节点具有稳定 origin 标识。路径→代码→解释后按 Escape 或切回路径会恢复原节点；节点消失时安全回退到路径 tab，焦点不落在隐藏面板。
- 最近位置由 SQLite v6 加法迁移保存，字段仅含不透明 `projectId`、`fileId`、`explanationId`、选择行号和时间戳；不保存绝对路径、目录授权或原生权限句柄。
- “继续阅读”始终先等待独立的恢复槽初始化 Promise，再调用原生目录选择器；读取期间入口显示加载状态并禁用，不以通用 persistence 状态代替。只有重新生成的项目 ID 与记录一致时才恢复文件、解释和有效行号；错项目、删除/失效目标或旧版空记录均回退到阅读指南推荐路径并给出说明。
- v6 复用现有数据库安全链：迁移前经验证备份、事务迁移、schema/integrity/foreign-key/计数检查及失败后非破坏恢复。0.10/0.11 fixture 继续通过迁移与重开测试。

## 补充原生测量（修复智能体，2026-08-09）

本节更新并优先于此前“无法可靠捕获窗口”的历史记录。检查在隔离的 `XDG_DATA_HOME`、`GDK_BACKEND=x11` 下运行真实 Linux/WSLg Tauri 窗口，通过 WebKit Inspector 审计；不保存包含源代码、提示词、模型输出或绝对路径的截图。

- 在 1180×820 与 760×760 两个真实 WebView 尺寸中，`innerWidth/innerHeight`、`body.clientWidth` 和 `body.scrollWidth` 与窗口逻辑宽度一致，未发现页面横向溢出；“下一步 / 真实代码 / 为什么重要”三项均存在，每次只显示当前面板。
- 在真实 WebView 的路径 origin → 代码 → 解释 → Escape 状态链中，最终回到原 `guide-step` origin 并恢复到该节点焦点。该 Escape 通过 Inspector 合成，**不能**作为真实 OS 键盘验收。
- 使用进程级 `GDK_SCALE=2`（未变更用户系统设置）时，逻辑 WebView 为 760×760、DPR 为 2，页面无横向溢出、三项切换栏各约 248px。测试显示器仅 1280×720，物理窗口 1520×1520 会超出屏幕，因此这只验证缩放机制和 DOM 溢出，不构成完整 200% 视觉验收。
- 关键文本样本计算对比度为 14.15、5.43、10.25、10.30，均超过 4.5:1；这不是全界面对比度穷举。
- 隔离数据目录无模型配置时，模型状态显示“模型未配置”，代码与解释面板仍有既有可读内容；未隔离网络，不能声称完整离线验收。

仍未完成且保持 R2 阻塞：真实 OS 键盘与可见焦点、原生目录选择器、关闭重启后的重新授权恢复、`prefers-reduced-motion`、长内容压力、完整 200% 视觉检查与全界面对比度。WebKit Inspector 缺少 Input domain，而窗口控制工具无法稳定捕获目标 WSLg 窗口；为避免误操作其他应用，未发送不可靠的坐标或按键输入。临时配置和 Tauri 进程均已清理。

## 监督复审结论（2026-08-09）

Terra 极高监督智能体已复审两轮。启动时继续阅读的空恢复状态竞态已关闭：继续入口会等待独立的恢复初始化 Promise，读取期间禁用，deferred 回归证明不会以空状态打开 picker，最新自动门禁为前端 301 项、Rust 122 项以及 Linux 7 项门禁通过。

原生响应式与无障碍人工验收问题仍为 P1。已取得的真实窗口/WebView 测量不足以替代真实 OS 键盘、picker、重启重新授权、reduced-motion、长内容、完整 200% 视觉与全界面对比度验收。因此 **R2 为 `FAIL`，不得创建阶段提交、不得进入 R3，也不得宣称产品或发布完成。**

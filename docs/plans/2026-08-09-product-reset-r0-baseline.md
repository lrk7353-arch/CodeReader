# CodeReader 产品复位 R0 基线

**状态：** 已建立；本文件是 R1 以前的可审计基线，不是功能验收通过声明。

**采集日期：** 2026-08-09
**范围：** 当前 `codex/product-reset` 工作树；只记录已存在行为、兼容义务和待修复缺口，不改变产品功能。

## 1. 可重复采集方式

在干净依赖环境、仓库根目录执行以下命令，并将命令、退出码和失败摘要回填到本文件第 5 节：

```text
npm run format:check
npm run lint
npm test
npm run build
npm run cargo:check
npm run cargo:test
npm run cargo:clippy
```

`npm test` 覆盖前端行为、反馈脱敏和操作代次相关测试；`cargo:test` 覆盖 SQLite 迁移、备份/恢复、提示词、模型配置和原生服务测试。发布打包和四平台原生 smoke 是 R5 门禁，不能由本 R0 环境代替。
